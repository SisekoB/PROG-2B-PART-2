# RaceDay Part 2


# Roles

- Organiser: creates, edits and deletes events and categories, views event enrolments and records results.
- Participant: views events and categories, manages their own profile, enrols in events and views their enrolments and results.

# Setup

1. Open `RaceDay.Api/appsettings.json` and update the connection string if needed.
2. Open `RaceDay.Api.sln` in Visual Studio.
3. Run `dotnet restore`.
4. Run `dotnet build`.
5. Run `dotnet test`.
6. Run the API. Swagger is available at `/swagger` in Development mode.
